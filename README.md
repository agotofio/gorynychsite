# Art-Pub Gorynych — Цифрове меню

Односторінковий digital-menu сайт для Art-Pub Gorynych (Чернігів, просп. Перемоги, 104).
Vanilla HTML/CSS/JS, без збірників і фреймворків.

## Структура проєкту

```
/
├── index.html               # розмітка сторінки, SEO/meta, Schema.org
├── admin.html               # локальний редактор меню
├── admin.js / admin.css     # логіка та стилі редактора
├── styles.css                # усі стилі (CSS variables, responsive, a11y)
├── script.js                  # завантаження даних, пошук, фільтри, quick view
├── data/
│   └── menu.json              # усі категорії та страви (єдине джерело даних)
├── assets/
│   ├── brand/                 # логотип
│   ├── decor/                 # декоративні елементи (дракон)
│   └── dishes/                # фото страв (.jpg + .webp + thumbs/)
├── favicon/                   # favicon.ico, apple-touch-icon, icon-192/512
├── manifest.webmanifest       # PWA-манифест
├── sw.js                      # offline-кеш оболонки та меню
├── robots.txt
├── sitemap.xml
└── README.md
```

## Запуск локально

Це статичний сайт — потрібен лише локальний веб-сервер (fetch() не працює з `file://`):

```bash
python3 -m http.server 8080
# або
npx serve .
```

Відкрити `http://localhost:8080`.

## Де знаходиться меню

Усі страви й напої описані в `data/menu.json`. Скрипт (`script.js`) завантажує цей файл
через `fetch()` і сам будує розмітку — редагувати `index.html` чи `script.js` для зміни
меню **не потрібно**.

### Структура `data/menu.json`

```json
{
  "meta": { "venue": "...", "address": "...", "phone": "...", ... },
  "categories": [
    {
      "id": "grill",
      "name": "Мангал меню",
      "note": "м'ясо, риба, бургери",
      "type": "food",
      "items": [
        {
          "id": "grill-bourger-horynych",
          "name": "Бургер «Горинич»",
          "description": "Фірмовий бургер з картоплею та соусом.",
          "weight": "420/100/50 г",
          "price": "360",
          "image": "img_3568",
          "imgW": 1000,
          "imgH": 1000
        }
      ]
    }
  ]
}
```

- `type` категорії: `"food"` або `"drinks"` — визначає фільтри «Страви» / «Бар».
- `image` — ім'я файлу без розширення з `assets/dishes/` (має існувати `.jpg` і бажано `.webp`).
- Для карток автоматично використовуються легкі AVIF/WebP-мініатюри з
  `assets/dishes/thumbs/`; оригінал залишається доступним для quick view.
- Поле `ingredients` використовується як «Склад» у quick view лише після звірки
  з меню закладу. Якщо його немає, опис залишається описом, а сайт пропонує
  уточнити склад у персоналу. Не визначайте рецепт або алергени за фотографією.
- `imgW` / `imgH` — реальні пропорції зображення (для запобігання layout shift). Якщо не
  вказані, використовується безпечне значення за замовчуванням.
- Якщо `price` відсутній або порожній, автоматично підставляється «уточнюйте».
- Порожні категорії або биті записи (без `name`) відсіюються на льоту — сайт не впаде.

## Як додати страву

1. Відкрити `data/menu.json`.
2. Знайти потрібну категорію за `id` (або створити нову — вона автоматично зʼявиться в
   навігації та фільтрах).
3. Додати обʼєкт у масив `items` з унікальним `id`, `name`, `price` (інші поля — опційні).
4. Зберегти файл. Оновити сторінку в браузері — правки застосуються без змін коду.

## Як замінити фотографію

1. Покласти нове фото у `assets/dishes/` у форматі `.jpg` (наприклад `img_1234.jpg`).
2. Створити WebP-версію поруч (`img_1234.webp`) для швидшого завантаження — це можна
   зробити будь-яким конвертером (`cwebp`, Squoosh, Photoshop «Save for Web»).
3. Створити мініатюри `assets/dishes/thumbs/img_1234.webp` та
   `assets/dishes/thumbs/img_1234.avif` шириною приблизно 480 px.
4. У `data/menu.json` вказати `"image": "img_1234"` (без розширення) для відповідної страви.
5. За бажання оновити `imgW`/`imgH` реальними пікселями зображення.

Якщо файл зображення відсутній або не завантажився — картка автоматично покаже
акуратний fallback (фірмовий значок дракона) замість «зламаної» іконки браузера.

## Як змінити контакти

Телефон, Instagram, адреса та години роботи прописані у трьох місцях, які варто
оновлювати разом:

- `index.html` — блок `<header class="topbar">` (`tel:` посилання, Instagram) і секція
  `<div class="intro-meta">` (адреса, години).
- `index.html` — блок `application/ld+json` (Schema.org `BarOrPub`) для пошукових систем.
- `data/menu.json` → `meta` (довідково, використовується для майбутніх інтеграцій).

## Як оновлювати меню через редактор

Після запуску локального сервера відкрити `http://localhost:8080/admin.html`.
Знайти потрібну позицію, відредагувати поля та зберегти зміни. Редактор зберігає
чернетку у браузері; кнопка «Завантажити menu.json» створює готовий файл для заміни
у папці `data/`.

Редактор є локальним інструментом без авторизації. Не публікуйте `admin.html` у
відкритому доступі без додавання авторизації або серверної CMS.

## Як зібрати / задеплоїти

Збірка не потрібна — це готовий статичний сайт. Достатньо завантажити весь вміст
репозиторію (окрім, за бажання, `README.md`) на будь-який статичний хостинг:
GitHub Pages, Netlify, Vercel, Cloudflare Pages або звичайний shared-хостинг через FTP.

Перед деплоєм на прод рекомендується:

1. Замінити `https://artpubgorynych.com.ua/` в `index.html` (canonical, Open Graph),
   `robots.txt` і `sitemap.xml` на реальний домен.
2. Перевірити, що `data/menu.json` віддається сервером з `Content-Type: application/json`.

## Вимоги до зображень

- Формат: `.jpg` (fallback), `.webp` та AVIF-мініатюри для швидкого завантаження через
  `<picture>`.
- Рекомендоване співвідношення сторін: 1:1 (квадрат) — картки та hero-стрічка розраховані
  саме на нього. Для quick-view модалки допустиме 4:3.
- Розмір: оптимально 800–1200 px по довшій стороні; більші файли будуть автоматично
  зменшені браузером, але зайва вага сповільнить завантаження.
- Завжди вказуйте `imgW`/`imgH` у `menu.json`, якщо відомі реальні пропорції — це запобігає
  «стрибкам» верстки (CLS) під час завантаження.

## Технічні примітки

- Дані завантажуються асинхронно (`fetch`) з обробкою помилок: битий/відсутній JSON,
  порожні категорії та мережеві збої показують акуратний UI-стан замість білого екрана.
- Під час завантаження дані нормалізуються та перевіряються: дублікати/небезпечні
  ідентифікатори не ламають розмітку, пошкоджені розміри зображень замінюються безпечними
  значеннями, а шляхи до фото приймаються лише у дозволеному форматі.
- Пошук: debounce 180 мс, нормалізація регістру/діакритики/зайвих пробілів, коректна
  робота з кирилицею.
- Фільтри «Страви» / «Бар» / «З фото» автоматично блокуються (`disabled`), якщо для
  поточного пошукового запиту немає результатів у цій категорії.
- Якщо пошук прибирає всі результати активного фільтра, сайт автоматично повертається до
  «Все меню», щоб не залишати користувача на порожньому заблокованому фільтрі.
- Додаткові фільтри: «До 200 ₴», «На компанію», «До пива», «Коктейлі» та «Десерти».
- Категорії підтримують глибокі посилання: `/#grill` одразу прокручує до розділу
  «Мангал меню», а URL оновлюється через `history.replaceState` (без накопичення
  записів в історії — Back не «пролистує» кожну переглянуту категорію).
- Quick view: клік/Enter/Space на картці відкриває модальне вікно (на мобільних — bottom
  sheet) з фокус-трапом, закриттям по `Esc`/кліку поза вікном і блокуванням скролу фону.
- Швидкі дії ведуть до дзвінка та Google Maps, а дата оновлення меню береться з `meta.updated`.
- Service Worker кешує оболонку та останню успішно завантажену версію меню для роботи
  при нестабільному з'єднанні.
- Локальний редактор дозволяє змінювати назву, опис, склад, ціну, вагу/об'єм, фото
  та доступність позицій без ручного редагування JSON.
- Increased accessibility: видимий фокус, `aria-live` для пошуку та сітки меню, семантичні
  `<nav>`/`<main>`/`<footer>`, `noscript`-повідомлення, коректна назва модального вікна,
  `prefers-reduced-motion` вимикає анімації.

## Відомі обмеження

- Редактор меню працює локально та експортує `menu.json`; для спільного онлайн-редагування
  кількома працівниками все ще потрібні backend/CMS або Google Sheets.
- Немає автоматичного аудиту цін/наявності — оновлення повністю на відповідальності
  персоналу.
- Контент Open Graph-зображення (наразі використовується логотип) можна замінити на
  окрему hero-картинку закладу; посилання на Google Maps веде на пошук за адресою.
# Фотографии из Telegram — 10 октября 2026

В `data/telegram-photo-review.json` записано соответствие всех 106 фотографий их карточкам. Несколько ракурсов одной позиции хранятся в массиве `photos` и открываются в галерее карточки.

Вкладка «Невідоме» содержит фотографии без уверенного соответствия меню и позиции, которых нет в текущем меню. Эти карточки имеют `pending: true`, не входят в обычное меню и не показывают цену или вес. Для переноса после уточнения переместите карточку в нужную категорию, измените `type`, удалите `pending`, заполните подтверждённые данные. Если позиция уже существует, перенесите её `photos` в существующую карточку, чтобы не создавать дубликат.

Составы Chili Sour, Very Peri и Baby Blue взяты из подписей на фотографиях; источник указан в `ingredientsSource`. Фотографии не подтверждают актуальность цен: дата проверки меню сохранена, дата обновления фотографий указана отдельно в `meta.photosUpdated`.
